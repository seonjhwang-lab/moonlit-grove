# 달빛 숲의 수호자 (Moonlit Grove)

원작 16비트 감성의 탑다운 액션 어드벤처 프로토타입.

- 내부 프로젝트명: **Moonlit Grove**
- 버전: **v0.1.0** (Prototype 0.1)
- 기술: HTML / CSS / Vanilla JavaScript / HTML5 Canvas (프레임워크 없음)

기준 문서: [game_design.md](game_design.md) — 모든 구현은 이 문서의 범위를 따릅니다.

---

## 실행 방법

`index.html` 을 브라우저에서 직접 열어도 동작합니다(모든 스크립트는 클래식 스크립트).

로컬 서버로 실행하려면:

```bash
python -m http.server 8123
```

이후 브라우저에서 `http://localhost:8123` 접속.

정적 파일만 사용하므로 어떤 정적 호스팅(GitHub Pages, Netlify 등)에도 그대로 배포할 수 있습니다.

## 맵 구조 (달빛 숲 — 초입)

- 맵 크기 **1440 × 810** (화면의 3×3배). 카메라가 플레이어를 따라가며 맵 밖은 보여주지 않습니다.
- 남북으로 흐르는 **물길(x=1000~1130)** 이 오른쪽 보물 지역을 완전히 갈라놓습니다.
  덩굴 다리(PHASE 10) 없이는 건널 수 없다는 것을 flood fill 테스트로 검증했습니다.
- 강둑에 서면 보물 예정지(x≈1200)가 화면 안에 들어옵니다 —
  "지금은 못 가지만 저기 뭔가 있다"를 먼저 보여주기 위한 배치입니다.
- 지면(풀·흙길·물·꽃)은 오프스크린 캔버스에 한 번만 굽고 매 프레임 blit,
  나무·바위는 플레이어와 **발 높이(y) 순으로 정렬**해 앞뒤 관계를 만듭니다.

## 렌더링 방식

- 내부 해상도 **480 × 270 (16:9)** 캔버스에 그린 뒤 화면 크기에 맞춰 확대합니다
  (`image-rendering: pixelated` 로 픽셀 보존).
- 한글 텍스트는 캔버스가 아니라 캔버스 위에 겹쳐진 **DOM UI 레이어**에서 렌더링해
  작은 해상도에서도 가독성을 유지합니다.
